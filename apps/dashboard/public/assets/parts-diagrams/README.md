# Parts Diagrams

This directory contains technical diagrams for machine parts used in the parts list modals.

## Bearing Clearance

- **crankshaft.png** - FIGURE 1006B — CRANKSHAFT PARTS
  - Exploded view diagram showing crankshaft components
  - Used in the Bearing Clearance section parts modal
  - Recommended dimensions: 1200x900px or higher resolution

## Adding New Diagrams

1. Save the diagram image to this directory
2. Update the corresponding section component to include the `diagramImage` property in the `SectionStatusCard` configuration
3. Use descriptive filenames (e.g., `section-name-diagram.png`)

## Image Requirements

- Format: PNG, JPG, or SVG
- Resolution: High enough to be readable when zoomed
- File size: Optimize for web (typically < 1MB)
